## 🚀 Featured Projects

### 🧘 [AcroFinder](https://github.com/jacopo-nesti/AcroMap_Italy) — [www.acrofinder.it](https://www.acrofinder.it)

Piattaforma web sviluppata con React per trovare community, jam e corsi di Acroyoga in tutta Italia, con ricerca per città, mappa interattiva e pagine dedicate alle community.

### 🔄 [Vudoo Base Connector](https://github.com/jacopo-nesti/vudoo-base-connector)

Progetto ideato e progettato durante il periodo di stage per automatizzare la sincronizzazione dei cataloghi prodotto da Vudoo a Base.com.

Ho curato progettazione del flusso, coordinamento, integrazione delle funzionalità, review delle Pull Request, testing e validazione finale, con il contributo del team di stagisti.

Il sistema gestisce normalizzazione e validazione dei dati, CREATE/UPDATE selettivi, stock, categorie e produttori, DRY_RUN, rate limiting adattivo ed esiti incerti delle API. Include una CLI interattiva e **110 test automatici**.

### 📅 [Booking System](https://github.com/jacopo-nesti/booking-system)

Applicazione web full-stack sviluppata con Flask e SQLite per la gestione delle prenotazioni, con autenticazione, disponibilità degli slot, trattamenti e dashboard amministrativa.

### ✅ [Checkmate](https://github.com/jacopo-nesti/checkmate)

Web app Flask per la gestione di task personali con autenticazione utenti, area privata e operazioni CRUD.

### 🏥 [Gestionale Triage Pronto Soccorso](https://github.com/jacopo-nesti/triage-pronto-soccorso)

Applicazione da console in C++ per la registrazione dei pazienti e il triage: questionario sui sintomi con calcolo del punteggio di gravità e assegnazione del codice triage, sintomi specifici per area clinica e lista pazienti.

Sviluppato interamente a mano, circa 550 righe di codice. Progetto in corso.

### 🍝 [React Ricette](https://github.com/jacopo-nesti/React_Ricette)

Ricettario interattivo sviluppato con React e React Router, con dati recuperati da API esterne, ordinamento e sezioni espandibili per ingredienti e procedimento.
